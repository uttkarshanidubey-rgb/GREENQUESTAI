# 🌿 GreenQuest AI — Touch Grass

**Less scrolling. More exploring.**

GreenQuest AI is a simple outdoor adventure planner that encourages people to spend less time on screens and more time exploring the real world. It suggests outdoor activities based on the user's mood, available time, location, and interests.

This project is built using HTML, CSS, and JavaScript.

## 🎯 Problem Statement

People spend a lot of time using phones and computers, which can reduce the time they spend enjoying outdoor activities and nature.

GreenQuest AI helps solve this problem by suggesting simple, enjoyable outdoor missions that encourage users to step outside and explore their surroundings.

## 💡 Our Solution

GreenQuest AI allows users to choose their preferences and generates a suitable outdoor activity.

Users can discover new things, observe nature, explore their surroundings, and enjoy screen-free time.

## ✨ Features

- 🌱 **Personalized Outdoor Quests:** Get activities based on your mood.
- ⏱️ **Time Selection:** Choose between 10, 20, and 30 minutes.
- 🌳 **Location Selection:** Select a garden, park, balcony, neighborhood, or nature trail.
- 🎨 **Interest-Based Activities:** Enter interests such as birds, plants, or flowers.
- ⏰ **Outdoor Timer:** Track the time spent on your outdoor mission.
- 📱 **Responsive Design:** Use the website on desktop and mobile screens.
- 🔒 **Privacy-Friendly:** Preferences are processed locally in the browser; no account or API key is required.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all three source files are in the same folder.
4. Open `index.html` in your web browser.
5. Select your available time, mood, location, and interests.
6. Click **Generate My Quest**.
7. Start the outdoor timer and enjoy your mission!

No API key or external library is required for the current version.

## 🔓 Why Open Innovation Matters

This project uses standard web technologies that are widely available and easy to modify. Developers can inspect the code, customize activities, and build new features without depending on a proprietary website-building platform.

The current version runs locally in a browser and does not send user preferences to an AI server.

**Important:** The current activity generator uses predefined activities rather than a genuine AI model. Integrating an open-weight AI model would be a future step toward fully meeting the Touch Grass hackathon's open-source AI requirement.
